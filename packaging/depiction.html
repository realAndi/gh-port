GitHub CLI (gh)

GitHub's official CLI, built natively for jailbroken iOS

Pull requests, issues, releases, gists, Actions runs, repository management, and gh api for everything else — from a terminal on your phone.

What gets installed

A real ios/arm64 build of the upstream source. Not a patched macOS binary: Go supports iOS as a first-class target, so the compiler emits an iOS executable directly.

No Mach-O rewriting, no shim library, no JIT entitlements, and nothing is downloaded at install time. gh is MIT licensed, so the binary ships in the package. About 10 MB to download, 38 MB installed.

Repository

https://reallyitsandi.com/repo/

After installing

Sign in once, then use it normally:

gh auth login  →  approve in Safari  →  gh pr list

Zsh and bash completions are installed too.

Requires

  • A rootless jailbreak (/var/jb) — tested on Dopamine
  • iOS 15 or later, arm64 — tested on iOS 17.3 (iPhone 15 Pro)
  • Depends: zsh, git, uikittools — Sileo installs any that are missing. Recommends: openssh, for git@github.com remotes.

Notes

  • Tokens live in ~/.config/gh/hosts.yml, in plain text. gh normally uses the system keychain through /usr/bin/security, which iOS does not have, so it falls back to its config file — the same thing it does on Linux without a secret service. The fallback is automatic; --insecure-storage makes it explicit. Anything that can read your files can read the token.
  • gh's own update notifier is off. It would point at Homebrew or a desktop download, neither of which applies. Updates come through Sileo.
  • Extensions do not work, in either form. Script extensions fail at exec — a Go process on iOS cannot execve a file with a shebang. Binary extensions fail at install, because they publish darwin/linux/windows release assets and gh asks for ios-arm64. A hand-built, signed ios/arm64 binary extension does run, and gh's ! shell aliases work normally.
  • gh copilot cannot install its helper for the same reason.
  • Any previous gh on your device stays available as gh-legacy.
